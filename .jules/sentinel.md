## 2026-01-18 - Input Validation on Repo/Owner **Vulnerability:** Path Traversal / Argument Injection **Learning:** User input from CLI args was used directly in file paths and shell commands. Malicious input like `../` could cause path traversal, and special characters could cause argument injection. **Prevention:** Always validate user input against a strict whitelist (regex) before using it. Explicitly block `.` and `..` to prevent directory traversal.
